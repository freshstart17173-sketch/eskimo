Eskimo Studio — node/socket design reference

Sockets, cards, and the bottom bar — kept in the repo

Committed at docs/design/socket-redesign-v6.html so this doesn't get lost between sessions. Same node layout/fonts/sizes as v6 throughout — this round only touches: the progress bar's colour, card borders → borderless + a real Selected outline, hover cleanup, the detail pane's close/play buttons and section titles, and adds the real bottom player bar.

Theme:
Changed this round
  • Progress bar is true black/white, not flat grey — var(--ink) on a normal card (flips with theme automatically), var(--paper-fixed) (always white) on the Active card, since Active's fill is a fixed dark blue in both themes. Same rule the card already used for its own text.
  • Cards are borderless. The look you liked on the Active card (no visible border because its border-color matched its own fill) is now how every state works — separation comes from a soft shadow instead, same recipe the app's own .modal-card already uses.
  • Selected is a new state: a flat accent-colour outline (box-shadow ring, so it doesn't fight the border-radius a real border would). Active stays distinguished purely by its own fill colour — the two never need to look alike.
  • No chevron, no translate-on-hover anywhere. Hover is a flat background tint only; a small centred scale is the only click feedback left, and that only fires on press, never on hover.
  • Detail pane close button is the real .icon-btn (26×26, panel background, rgba(19,19,19,.08) hover) with the actual shipped × icon, not a bespoke bordered square.
  • Detail pane play button has no native bevel — added the app's real global button reset (background:none;border:0;font:inherit); without it a bare <button> keeps native chrome underneath a custom background, which is exactly what was showing through before.
  • Detail pane section titles are plain text — the little shape icon next to "Input"/"Output" is gone; shapes stay on the node card only.
  • The real bottom player bar is included, ported structurally from PerformPage.jsx/styles.css — now/next, scrub bar, volume — so this reference shows the full picture, not just the graph-side UI.
  • A theme toggle (top right) cycles system → light → dark so both themes are actually checkable here without touching OS settings.
Corrected after review
  • Sockets are all plain circles now — the square/triangle/circle-per-type system from v6 is gone. Type is shown by label text and column (left = input, right = output) only, matching what was actually asked for.
  • Removed the crossfade indicator from the bottom bar — that circular mix-progress dot exists in the real shipped bar (.player-bar-crossfade, PerformPage.jsx), but wasn't part of what was requested for this reference, so it's left out here.
Earlier history — changed v5 → v6
  • Countdown/progress strip removed from the node card entirely — a connected row on the node is just its shape and name now; the live state moved to the picker and the detail pane instead.
  • Drains right-to-left, always — v5 accidentally drained toward each row's own socket, flipping direction between columns.
