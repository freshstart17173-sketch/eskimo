Every screen, every control

Eskimo Studio is a graph-based DJ set editor: songs are nodes, produced transitions/intros/outros are the wires between them, and a set is whatever path is wired through the graph. This atlas walks all five screens plus the shell around them at the app's real component scale — same shadows, same type, same interaction recipes as styles.css — with a full control index under each one.

Everything below that can plausibly move on the page does: hover states, the theme toggle, the socket picker, the context menu. Static-only mockups are marked as such.

Search (/ or ⌘K)

Fuzzy-matches songs already on this canvas — not the whole library. Enter jumps to the first match; ←/→ step through the rest, each one re-centering the camera.

Match nav (‹ n/n ›)while searching

Steps the camera between search results without retyping.

Focus active

Re-centers the camera on whatever's actually playing — or fits the whole graph in view if nothing is.

Arrange for me

Runs the dagre auto-layout algorithm once and writes the result into every node's stored position — one-shot, not a toggle, so a manual drag afterward sticks.

Startbefore a set

Appears once something is wired to Start Set — begins playback there immediately.

Pause / Resume · Stoponce started

Stop ends the set outright — no confirm; the graph's own wiring into End Set is what makes an ending feel graceful.

Socket dots — None / Intro / Transition (left), None / Outro / Transition (right)

Click None/Intro/Outro to toggle it on or off. Transition is drag-only — drag from one song's Transition dot to another's to wire a produced crossfade.

↓in / ↑out counts

How many wires touch this song, at a glance.

Start Set / End Set nodes

Start: drag a wire to any song's Intro/None socket. End: purely informational — "part of your plan" once some song's output leads here.

Hover-✕ on an active edge

Disconnects that one wire. Deliberately not "click the line" — a stray click destroying a built set was a real, reported hazard.

Shift+drag to pan · drag to box-select

Plain click-drag draws a real multi-select box; panning moved to Shift+drag so a stray right-click-menu dismissal never fights the canvas's default gesture.

Add Node modal

Opened by "Add node here" — searches the library's unplaced songs only, placing whichever one you pick at the exact right-clicked spot.

Back

Restarts the current song from 0 — or, within the first few seconds of it, jumps back to whatever played immediately before. Always a plain cut.

Skip

Leaves for whatever's wired next right now, always a plain cut — never waits out or plays a wired transition's produced clip first.

Scrub bar

Drag to seek Now Playing's own master. No effect while a produced fragment (not the master) is what's actually sounding.

Next preview + crossfade meter

What's coming and how — the crossfade meter only appears within 8 seconds of the real handoff.

Volume

Collapsed to a plain icon until clicked; stored on the audio engine itself, so it survives navigating away and back.
