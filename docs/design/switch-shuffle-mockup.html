Shuffle (a socket modifier) and Switch (a new node type)

1. Shuffle — a modifier on a None/Outro row, not a new socket type

Hover a None or Outro row and a small "shuffle?" hint appears where a destination name would normally sit; click the row to toggle it. Once on, the socket's own dot is replaced entirely by a shuffle icon and the label reads "Shuffle" — there's no specific destination to name, since it lands on any other song in the library, decided fresh each time playback actually reaches it. Intro and Transition rows don't get this — both are inherently about one specific pairing, not an open destination.

2. Switch node — superposition until playback actually reaches it

Holds several candidate songs, each with its own real wiring. Idle (or whenever playback is anywhere else), it shows every candidate and where each one leads — nothing hidden, nothing decided. The instant playback actually reaches it, it collapses into what looks like a completely ordinary Active card for whichever candidate got picked — a small badge in the corner the only reminder it's a switch — showing only that candidate's own connections. The moment playback moves on, it reopens into the full list again.
